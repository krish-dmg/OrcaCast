# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |

## Reporting a Vulnerability

If you discover any security vulnerability in OrcaCast, please do not file a public issue.

Instead, please send an email to krish.7zip@gmail.com with:
- A description of the vulnerability
- Proof-of-concept steps or exploit code
- Potential impact and recommended mitigations

You will receive an acknowledgment within 48 hours and regular updates on progress toward a patch.
