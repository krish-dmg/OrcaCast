# Contributing to OrcaCast

Thank you for your interest in contributing to **OrcaCast**! We welcome bug reports, design ideas, feature enhancements, and pull requests.

## How Can I Contribute?

### Reporting Bugs
- Check the [Issues tab](https://github.com/krish-dmg/OrcaCast/issues) first to see if your bug has already been reported.
- If not, create a new issue detailing:
  - macOS version
  - Target device type (iOS / Android) and connection method (Wired USB / Wi-Fi)
  - Steps to reproduce
  - Expected vs actual behavior
  - Logs or error output if available

### Submitting Pull Requests
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes with clear messages (`git commit -m 'Add support for custom keymapping'`).
4. Push to your branch (`git push origin feature/amazing-feature`).
5. Open a Pull Request against the `main` branch.

## Code & Design Standards
- Keep diffs focused and cleanly structured.
- Do not introduce unnecessary dependencies or bloated wrappers.
- For UI assets and skins, adhere to the vector SVG standards and keep high-DPI scaling intact.
